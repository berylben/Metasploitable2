# 🛡️ Penetration Testing Portfolio: Metasploitable 2 Assessment & Business Impact Analysis

Welcome to my cybersecurity portfolio project! This repository showcases my hands-on penetration testing skills, technical methodology, and security assessment capabilities using **Metasploitable 2**—an intentionally vulnerable Linux virtual machine—as the target host.

Rather than focusing solely on exploitation, this project demonstrates a end-to-end security lifecycle: converting raw terminal technical findings into an executive-level **Business Impact Analysis (BIA)**, complete with risk ratings, CVSS scoring, and actionable remediation roadmaps.

---

## 🎯 Project Objectives

* **Demonstrate Core Pentesting Competencies:** Execute structured reconnaissance, service enumeration, vulnerability validation, and post-exploitation steps.
* **Bridge Technical & Executive Communication:** Translate complex exploits (e.g., buffer overflows, CGI parameter injections) into business risk and compliance impacts.
* **Provide Practical Hardening Guidance:** Offer prioritized remediation steps to mitigate vulnerabilities across infrastructure, web, and network service layers.

---

## 🛠️ Lab Setup & Environment

* **Attacking Machine:** Kali Linux (Rolling Release)
* **Target Machine:** Metasploitable 2 (`Ubuntu 8.04` / Linux 2.6.24)
* **Network Isolation:** VirtualBox Isolated Host-Only Subnet (`192.168.1.0/24`)
* **Primary Tooling:** `Nmap`, `NetExec` (`nxc`), `enum4linux`, `Nikto`, `Burp Suite`, `Metasploit Framework` (`msfconsole`), `sqlmap`.
